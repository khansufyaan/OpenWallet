Visa Multilateral Net Settlement on Canton — Interactive Simulator

A faithful in-browser simulation of the Daml model in this repo: bilateral SettlementObligations between each bank and VisaTreasury, settled atomically in USDC by one SettlementBatch transaction, with regulator disclosure. Switch parties to experience Canton's privacy: each party sees only contracts it is a stakeholder of. Every action is a "transaction" — if it throws, the whole thing rolls back.

How this maps to the Daml model

UsdcHolding → issuer-signed, owner-controlled token (plain template, not CIP-56).
Allocate funds → carves out the exact amount and discloses it to VisaTreasury only.
Execute settlement → one transaction: validate coverage + zero-net, collect from all net debtors, pool, pay all net creditors. Any failure rolls back everything.
Disclose → re-creates the contract with Regulator as observer, authorized by both signatories.

Simulator mirrors visa-settlement/daml/Visa/Settlement/*.daml — run dpm test for the on-ledger proofs.
