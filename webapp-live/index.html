Visa Multilateral Net Settlement ● LIVE · CANTON

This UI is connected to a real Canton ledger through the JSON Ledger API v2. Every button submits an actual Daml command against the visa-settlement DAR; every card below is a live contract on the participant node, filtered by what the selected party is allowed to see. Failures are real ledger rejections — Canton rolls the whole transaction back.

What's real here

Backend: dpm sandbox (Canton 3.5) with the project DARs uploaded.
Reads: POST /v2/state/active-contracts filtered by the selected party — the privacy you see is enforced by the participant, not the UI.
Writes: POST /v2/commands/submit-and-wait with Create/Exercise commands, actAs the selected party.
The atomicity demo produces a genuine CONTRACT_NOT_FOUND rejection from Canton when the batch references the spent holding.

Daml model: visa-settlement/daml/Visa/Settlement/*.daml · on-ledger proofs: dpm test
